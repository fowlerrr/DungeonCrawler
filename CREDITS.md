# Art credits

Third-party art used in `public/assets/`, shared by both the 2D (Phaser) and 3D (Three.js)
clients. Keep this file in sync if more assets from either pack (or a new pack) get used.

## Dungeon tiles — Penzilla

- Source: https://penzilla.itch.io/dungeon-crawler-map
- Files used: `public/assets/tilesets/Assets/Tiles_Medium/Tile01_Floor.png` (floor),
  `Tile02_Wall.png`, `Tile03_Wall.png`, `Tile04_Wall.png`, `Tile05_Wall.png`, `Tile08_Wall.png`,
  `Tile18_Wall.png` (the 2D game's floor autotile shapes; the 3D game uses `Tile01_Floor.png` and
  `Tile18_Wall.png` only, since 3D walls are real geometry and don't need the autotile trick),
  `Decor/Door.png` (2D exit door; every door in the 3D game, tinted per lock color)
- License: Penzilla Design Standard License (included as `PenzillaDesign_StandardLicense.pdf`
  alongside the downloaded assets). Summary:
  - Royalty-free for private/commercial use, **one project per purchase**, requires credit
    **"Graphics created by Penzilla Design"**.
  - **Free ($0) downloads are evaluation only** — royalty-free/commercial rights only apply
    once purchased for at least the suggested price.
  - No redistribution/resale; modifications allowed with credit and documented changes.
  - **Action needed before shipping**: pay at least the suggested price on the listing above,
    and add the required credit line somewhere in the game (e.g. an About/Credits screen).
